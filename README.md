## 方向

目的是制作一份以画面质量为最高优先级的整合包
性能开销也有考量，但被我排到第二优先级
音质为第三优先级
  因为人类观看视频时的感知约70%来源于眼睛
综合考量下：部分肉眼观感提升不是很明显，但性能开销巨大的，我暂时未加入，等待下一代显卡出来后再进行测试

大量使用gpu进行计算，因为cpu运行原理导致并不适合处理除解码外的画面实时计算。
