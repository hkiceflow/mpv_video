## 方向

1. 目的是制作一份以画面质量为最高优先级的整合包
2. 性能开销也有考量，但被我排到第二优先级
3. 音质为第三优先级
  3.1 因为人类观看视频时的感知约70%来源于眼睛
4. 综合考量下：部分肉眼观感提升不是很明显，但性能开销巨大的，我暂时未加入，等待下一代显卡出来后再进行测试

大量使用gpu进行计算，因为cpu运行原理导致并不适合处理除解码外的画面实时计算。

## 关于此安装包

github上制作的为懒人包，去除了大量未预设及不需要的算法等，有需要的可以找我要完整包。

1. 下载安装包后找到mpvnet.exe文件，即可使用
2. 进阶操作的使用教程在安装包中有
  1. mpv本体
  2. 着色器
  3. 滤镜
3. 图文教程看不懂的可在bilibili搜索我的频道观看视频中的系列教程，我的ID：iceflow_official
  1. 频道中的系列还包括了各种图像原理讲解
